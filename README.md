\# Projeto Notas dos Atletas

Projeto de certificação do curso DEVstart para calcular a média de atletas de ginástica artística.



\## 📋 Descrição

O sistema recebe um conjunto de atletas com suas respectivas notas, organiza os valores e calcula a média válida.



\## 📏 Regra de Negócio

Conforme os padrões da modalidade, o cálculo da média segue estas regras:

1\. Recebe cinco notas de 1 a 10.

2\. Elimina a maior e a menor nota.

3\. Calcula a média aritmética das três notas restantes.
